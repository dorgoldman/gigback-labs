# gigback.org — Real backlink/directory candidates (lever 3, Phase 5.3), 2026-09-13

## Why nothing was submitted this session

Submitting to an external directory means filling in a public form under GigBack's name — publishing
content, sometimes creating an account. That's outside what an unattended agent session does on its
own: AGENT.md's Decision authority section reserves "distribution/social posting" for Dor ("Dor
posts, you draft only"), and filling in a live external form is the same category of action. This
report is the draft — a Dor-approved next task should do the actual submitting, using the concrete
picks below.

Two low-quality inbound links were already found and flagged during T30 (`backlinkmasters.online`,
`seo.am.in` — auto-spam-directory links). Not covered again here; still pending a disavow-review
decision, still not urgent.

## Method note

Checked real, live sites only — no directory below is invented, and each was fetched/searched this
session, not recalled. Two separate targets exist and they're at different readiness stages:

- **gigback.org (the content site)** — public, indexed, real guides. Ready for outreach now.
- **GigBack CRM (crm.gigback.io)** — checked directly this session: **it's a bare login screen, no
  public marketing page, no pricing, no screenshots.** Every real software directory (Capterra,
  SaaSHub, G2, AlternativeTo) requires a public product page to list against. **This blocks all
  CRM-directory submissions until crm.gigback.io has one** — that's a product/marketing build item,
  not something this agent can create, and it sits outside gigback.org's own repo. Flagging it to
  `## Proposed` rather than treating it as done.

## Checked and ruled out

- **TechSoup Israel** (israel.techsoup.global) — real and active, but it's a *donation/discount* program (nonprofits get discounted Microsoft/Adobe/Salesforce licenses through it), not a directory that lists vendors. GigBack would need to become a donating software partner, a much bigger commitment than a directory listing — not what Phase 5.3 asks for. Not pursued.
- **GuideStar Israel** (guidestar.org.il) — the Ministry of Justice's official NPO registrar. Lists organizations, not tools or content sites; no listing mechanism fits gigback.org or the CRM. Not pursued.
- **Shift-Shatil's "digital tools" post** (shiftshatil.org.il) — a one-time blog article comparing Monday/Trello/Planner/Asana, not a directory. No submission mechanism, no external links even to the tools it names. Not pursued.
